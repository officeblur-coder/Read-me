# Lyra Comenzi — aplicația

- `/` meniul și comanda online · `/comanda/:token` urmărirea comenzii · `/receptie` consola recepției
- Linkuri de campanie: `/fb`, `/ig`, `/qr`, `/google`, `/tiktok`, `/wa`, `/flyer`
- Date: Supabase (vezi `../supabase`). Cheile publice sunt în `.env`.
- Publicare: Netlify construiește automat branch-ul `claude/lyra-orders-demo` (config în `../netlify.toml`).

Local: `npm install` apoi `npm run dev`.
